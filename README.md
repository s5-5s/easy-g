# О проекте

`easy-g` - офлайн-доступный PWA-учебник по геометрии для 5-11 классов.
Карточки правил хранятся в каталоге `cards/`, сгруппированы по темам в
`cards/index.json`, и каждая карточка может быть показана как текстом,
так и интерактивной 3D-сценой.

На текущем этапе интерфейс собран из двух постоянных зон:
слева стеклянный сайдбар со списком тем, справа область 3D-модели.
По клику тема раскрывается прямо в сайдбаре списком правил, а модель
загружается из выбранной JSON-карточки.

## Основные блоки интерфейса

- Левый сайдбар тем с раскрывающимися карточками
- Правая область 3D-модели

## Технологический стек

- JavaScript (ECMAScript 2022+)
- Нативный DOM API
- three.js (WebGL)
- CSS Grid/Flex
- JSON-карточки тем

## Принципы реализации

- Каждое правило хранится в отдельном JSON-файле в `cards/`.
- `cards/index.json` задает структуру тем и список карточек правил.
- 3D-движок на three.js процедурно строит академические сцены по правилам.
- Модель всегда центрируется относительно сцены, а масштаб меняет только
  дистанцию до камеры, не смещая точку фокуса.
- Визуализация карточек использует ограниченную палитру: черный, красный, белый.
- Крупные UI-блоки реализованы отдельными компонентами-классами.
- Структура репозитория поддерживается в `struct.md` и `ui-struct.md`.
